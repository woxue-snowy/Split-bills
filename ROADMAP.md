# Roadmap

SplitSnap aims to stay small and useful.

This roadmap is intentionally focused on improving the core bill-splitting workflow rather than turning the project into a large financial platform.

## Completed

- [x] Receipt image upload
- [x] Server-side receipt OCR
- [x] Editable receipt data
- [x] Participant management
- [x] Item-level participant selection
- [x] Equal item splitting
- [x] Percentage splitting
- [x] Exact-amount splitting
- [x] Share / weight splitting
- [x] Tax, service fee, and tip allocation
- [x] Penny-safe calculations
- [x] Single-payer settlement
- [x] Debt simplification
- [x] Unit tests for core split logic

## Next

- [ ] Improve mobile layout and small-screen editing
- [ ] Persist the current bill locally in the browser
- [ ] Improve validation messages for custom split modes
- [ ] Add more edge-case tests
- [ ] Add a lightweight demo screenshot or GIF to the README
- [ ] Improve accessibility and keyboard navigation

## Later

- [ ] Optional receipt history stored locally
- [ ] Shareable settlement text / link format
- [ ] Additional receipt parser fixtures
- [ ] International currency formatting improvements

## Out of Scope for Now

To keep the project maintainable, these are not current priorities:

- User accounts
- Social feeds
- Real-time collaboration
- Built-in payments
- Large database infrastructure
- Complex multi-currency settlement
